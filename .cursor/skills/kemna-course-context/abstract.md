# Abstract lesson slots

Shared by every Kemna subject. Field names in code may differ; slot meaning does not.

## Layers

Course → unit → lesson → test. Agents write the lesson. Nobody writes the 100-question bank by hand.

## Slots the creator fills

| Slot                | Norm                                                                                      |
| ------------------- | ----------------------------------------------------------------------------------------- |
| Goals               | 3 short lines in the student language                                                     |
| Theory              | 1–2 schemas: formula, meaning, 2 examples, one watchOut                                   |
| Lived example       | 4 steps that reuse those formulas (dialogue, worked problem, observation, or video clips) |
| Terms               | 8–10, hint does not leak the answer                                                       |
| Key phrases / facts | 3 ready units                                                                             |
| Rule                | Short rule + 4 examples                                                                   |
| Source text         | Short; terms appear inside; sentences are not fragments                                   |
| Manual checks       | 1–2 items, 4 options, one answer                                                          |

## Pedagogy

- Student language first, then the object of study.
- One contrast per lesson beats a list of synonyms.
- Topic from the curriculum; wording original. Do not scan a textbook page.
- UI, goals, meaning, watchOut, explanations: Belarusian.

## Three sieves (corrector)

1. **Relevance** — plan goals, contrast, recap, and (for geography) video clips appear in the lesson.
2. **Determinism** — one correct answer; hints do not leak.
3. **Sequence** — why → formula → examples → lived example. The example must not introduce a formula that was not taught yet.
